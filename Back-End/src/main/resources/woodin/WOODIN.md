# 우딘(WOODIN) 단가·카테고리 정리

우딘 견적에 사용되는 단가표(45~47p) 기준으로 DB 카테고리·제품·옵션 구성을 정리한 문서입니다.

---

## 1. 개요

- **회사 코드**: `WOODIN`
- **백엔드**: 견적 계산 시 `VariantCalculator`가 다음 카테고리 코드를 지원합니다.  
  `FOAM_FRAME`, `SLIM_FRAME`, `WOOD_FRAME_GIRD`, `FRAME_WINDOW`, `MOLDING` 등
- **프론트**: 견적 탭에서 우딘 회사(WOODIN_COMPANY_ID) 선택 후, 카테고리 → 제품 → 규격(spec/type) → 옵션 선택 후 단가 계산·장바구니 추가. PDF에서는 estimate 항목을 회사별로 구분해 **【 우딘 】** 섹션으로 출력합니다.

---

## 5. API·프론트 연동 참고

- **회사 ID**: `companies.code = 'WOODIN'` 인 회사 id 사용 (프론트 상수 `WOODIN_COMPANY_ID`와 일치시키기).
- **카테고리 목록**: `GET /api/.../categories?companyId={우딘 id}` → 발포 문틀, 슬림 문틀, 목재 문틀·가틀, 문틀/창틀, 몰딩 등 반환.
- **제품·규격·옵션**: 기존 쉐누 견적과 동일하게 `product_id` 기준 variants(spec_name, type_name), options 조회 후 단가 계산.
- **장바구니·PDF**: 우딘 견적 항목에는 `companyId: WOODIN_COMPANY_ID`를 넣어 주면 PDF에서 **【 우딘 】** 섹션으로 출력됩니다.
